CFB construction recipe (research-backed)

DraftKings Classic: QB, 2 RB, 3 WR, FLEX (RB/WR), SUPERFLEX (QB/RB/WR). $50k. No DST. TEs are WRs.

  • Two QBs by default. 26 of 28 flagship GPPs on 12+ game slates were won with a quarterback in Superflex. Keep “QB only at Superflex” on for main slates; uncheck on 1–3 game slates.
  • Don’t overstack. Winning QBs had ≥1 pass catcher 74% of the time and two pass catchers only 14%. Default GPP stack is QB + 1 WR. Use QB + 2 WR for pocket passers with condensed targets.
  • Dual-threat QBs can go naked. If the ceiling is rushing TDs, skip the WR stack and spend up elsewhere.
  • Max 2 WR from one team on large slates (built into the solver). Triple stacks almost never win 12-game GPPs.
  • Volume + matchup over stars. Bell-cow carries and condensed target share beat recruiting rankings, especially early season.
  • GPP mix: at least two players under 20% own and one under 10%. Ownership is inefficient in CFB but still condenses on chalk.
  • Showdown kickers hit fewer CFB optimals than NFL. Leave Min K/DST at 0 unless the script is FG-heavy.

Exposure tools (what to use and why)

  • Exposure tiers (dropdown under player name) — best default. Core 30–40% · High 20–30% · Mid 15–20% · Low 5–10% · Lower 1–5%. Boosts optimizer weight even if projection is 0 (preseason).
  • Edit Projected FP (click the Projected FP cell in the Player Pool) — one of the best ways to control exposure. The optimizer maximizes total projected points, so:
    • More exposure → raise that player’s fantasy points (they become more attractive in the solve).
    • Less exposure → lower their fantasy points (they get used less often or fade out).
    This is especially useful in preseason when base projections are thin or zero — bump players you like so the optimizer naturally lands on them more.
  • Presets — set global style (Cash vs GPP vs K/DST). Start here, then add only a few player tiers.
  • Stacks — force QB/CPT + pass catcher(s) in a % of builds. Recipes: QB+1 WR (default winner), QB+2 WR for pocket passers, optional same-game RB bring-back. No DST to fade.
  • Groups — structural “at least N of these players.” Prefer 1 group, not 4.
  • Min K/DST (Showdown) — same idea as a group of kickers/DSTs, but simpler. Don’t also Group the same players.
  • CPT / FLEX bulk exposure (Showdown) — set all Captains or all FLEX rows at once, then tighten favorites with tiers.

Don’t stack everything: one preset + a handful of tiers + optional stacks beats Groups + tight ownership + K/DST + 15 min-exposures. The tool warns before Run if it detects overlap.

Classic / main slate — recommended flow

  1. Pick the Classic slate. Cash: Cash Floor Lock, Eat the Chalk, or Cash 3RB Floor. GPP: Milly Winner, Four Uniques, or GPP Mini-Stack.
  2. Tag 6–12 players with exposure tiers (your cores, values, fades via Lower).
  3. Open the Stacks Lab tab to rank pairs, 3-mans, and opposing-RB bring-backs, then add 1–2 stacks at 20–40%.
  4. Leave Min Projected FP at 0 unless you intentionally want to cut the pool.
  5. Run 20–150 lineups depending on multi-entry size. Review exposure table + leverage board.

Cash → higher total ownership band, lower randomness. GPP → lower max exposure, more uniqueness, stacks + leverage.

Showdown — recommended flow

  1. Select the Showdown slate (or click a Showdown preset — it auto-switches).
  2. Pick one structure: team split (3–3 / 4–2) or Min K/DST (e.g. 2 for FG/DST-heavy preseason), not both at extremes.
  3. Use CPT/FLEX bulk bands if needed, then tier 4–8 favorites (CPT and FLEX rows separately).
  4. Add 2–4 specific stacks (QB+WR+TE, QB+2 PCs, optional bring-back). Or flip Classic correlation recipes so every QB used must bring those pieces.
  5. Run 20–50, check CPT% vs FLEX% on your QBs and that K/DST count holds.

Example: single-game Showdown script (Hall of Fame / preseason style)

Goal: ≥2 K/DST every lineup, both QBs in the mix with correlated stacks, preferred RBs, diversified CPT.

  • Settings: Min Kickers+DSTs = 2 (do not also Group those same players). Wide ownership band. No heavy Groups.
  • CPT plan: King ~15%, Beck ~15%, skill captains mixed (e.g. Reed & Davis ~12% as highest non-QB CPT), K and each DST as CPT in a couple builds only.
  • Stacks: King→Reed (primary) / Horn (secondary); Beck→Wallace (primary) / Virgil (secondary). When Reed is CPT, put King in FLEX for correlation.
  • RBs: Knight & Kiner higher tiers; Davis mid; Tyus lower.
  • Correlation rule: If a kicker is CPT, fade that team’s QB (FG script ≠ TD script). Example: ARI K as CPT → lean CAR offense (King/Reed), not Beck stacks.
  • Tiers: High/Core on your two QBs and primary stack mates; Mid on secondary; don’t tier 20 players.

That one script uses: Min K/DST + stacks + a few exposure tiers. Not Groups + preset + narrow ownership all at once.

Quick checklist before Run

  • One global style (preset or ownership band), not three.
  • Classic: ≤12 tiered players. Showdown: ≤8 tiered rows (CPT/FLEX count separately).
  • Stacks for correlation; Groups only if you still need a hard “at least N of set.”
  • Export CSV for DraftKings; use checked-lineup export after sim if you only want winners of the sim.

    How to Use Properly

    1. Slate — Pick Classic or Showdown. Data loads from GitHub or the CFB Google Sheet fallback.
    2. Pool — Filter players. Left-click name = stack partners. Right-click = Force / Core / Exclude / Injury / Game Stack.
    3. Presets — Hover any preset for what it optimizes (Cash, GPP, Leverage, etc.).
    4. Constraints — Max exposure, ownership range, min unique players, multi-entry target.
    5. Stacks — Optional QB/CPT + receiver stacks and player groups.
    6. Run — Optimizer builds lineups. Review summary + exposure.
    7. Leverage Board — Find underowned production.
    8. Simulation — Monte Carlo + contest field for Top 1% / Boom % / Floor.
    9. Export — DK CSV upload or Copy as Text for Discord.

    Cash → high floor. GPP → lower exposure + leverage + stacks + strong sim Top %.
